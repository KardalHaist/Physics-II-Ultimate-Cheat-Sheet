# Physics II Ultimate Final Exam Cheat Sheet (2023-2026)

An ultra-dense, two-page HTML cheat sheet optimized for Physics II (Calculus-based Electricity & Magnetism). This document was structured using LLM-assisted analysis of 2023-2026 Pearson Physics curriculum patterns to ensure every high-frequency problem type and "pitfall" is addressed.

## 🚀 Key Features

- **High Density Layout:** 3-column grid, 7pt Cambria font, and minimized margins to fit an entire semester of content onto 1 double-sided sheet.
- **AI-Optimized:** Formulas and "Exam-Flagged" sections are prioritized based on common exam problem distributions (Gauss's Law, RC/RL/LRC circuits, Ampere's Law, and Maxwell's Equations).
- **Exam Triage System:** A "Keyword → Formula" lookup table on Page 2 for rapid identification of equations during timed tests.
- **Unit & Prefix Reference:** Includes SI unit equivalents and power-of-10 prefixes to prevent simple conversion errors.
- **Common Pitfall Flags:** Explicit warnings for common student mistakes (e.g., Weber vs. T·m², capacitor connectivity behavior, and RHR rules).

## 🖨️ Printing Instructions (CRITICAL)

Because this sheet uses specific CSS `@page` parameters to achieve maximum density, use these settings to ensure it doesn't cut off:

1.  **Open** the `.html` file in Chrome or Edge.
2.  **Print (Ctrl+P)** and set the Destination to **"Save as PDF"** first.
3.  **Margins:** Set to **None** (The HTML already has a 0.22in margin built-in).
4.  **Scale:** Set to **100** or **Actual Size** (Do not "Fit to Page").
5.  **Background Graphics:** **CHECK THIS BOX** (Required for the color-coded exam sections and shaded headers).
6.  **Headers/Footers:** **UNCHECK THIS BOX**.
